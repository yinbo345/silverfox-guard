银狐防护小贴士

📦
「官网」下载的压缩包别急着开。银狐常把木马伪装成发票、订单、补贴、工资表等文档，打包成带解压密码的压缩包发给你。收到压缩包先用杀软扫描，尤其附密码的更要警惕。
🔄
警惕「版本过低 / 请更新插件」弹窗。银狐惯用伪造的浏览器、Flash、插件更新提示诱导下载木马。真更新请走软件内或官网，别点网页弹窗里的下载。
🌐
认准官方域名，防连字符 / 错拼。像 team-viewer.us、any-desk.net、sougou 这类「看起来像」的多为仿冒。下软件只走 verified 官方站，别信搜索置顶的「官网」。
💬
陌生群聊 / 二维码别乱点。银狐多在 QQ / 微信群发带毒文件、诱导扫码下载。不进陌生群、不扫来路不明二维码、不下载群友发的「资料包」。
👁
打开系统「显示文件扩展名」。避免 .pdf.exe、报告.doc.exe 这类双扩展名伪装。看到 .exe/.scr/.bat/.ps1 等可执行文件，先杀软查一遍再运行。
🏢
单位「税务稽查 / 补贴申领」主题要核实。收到此类邮件、文件或群通知，务必通过官方渠道（电话 / 窗口）核实，别直接打开附件或扫码。

本扩展只是辅助防线，最稳的防护仍是：正版杀软保持更新 + 不轻信来源不明的文件与链接。
