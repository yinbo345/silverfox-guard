中招后急救步骤：

  1. 点击上方按钮下载 360 系统急救箱（官方绿色版，无需安装）。
  2. 用解压软件（如 7-Zip）把压缩包解压到桌面等好找的位置。
  3. 进入解压后的文件夹，双击主程序（.exe）打开急救箱主界面。
  4. 若双击无反应或被拦截——部分银狐病毒会禁掉一切 .exe 程序——请改双击同目录下的 .com 文件。.com 是 Windows 最底层的 DOS 应用程序，通常不被此类病毒拦截。
  5. 勾选 全盘扫描 与 强力模式，点击 开始查杀，等待完成后重启电脑。
银狐木马常会屏蔽常规杀毒软件。360 系统急救箱为独立绿色版，不依赖已安装的安全软件，更适合中招后急救。

银狐环境检测

本功能由常驻 Windows 服务的「银狐环境检测程序」（单个 EXE，兼作系统服务与浏览器联动宿主）提供实时检测——安装后作为后台服务自动运行，无需手动打开、无托盘、无独立窗口。约每 3 分钟扫描本机进程 / 注册表 / 计划任务 / 网络连接 / 文件，盾牌图标绿=环境正常、红=疑似中银狐，结果仅在扩展内显示。

实时环境状态
面板显示服务端最新一轮扫描的缓存结果，每 30 秒自动读取一次（仅读取结果，不触发扫描，不占 CPU）。扫描由服务端按节奏执行：每 3 分钟自动巡检，或点右侧「立即检查」手动全量扫描。
GPU 加速扫描
将深层扫描的「家族特征字节串匹配」交给显卡批量计算（默认关闭）；切换后对下一轮扫描生效。需较新显卡驱动，无可用 GPU 时自动回退 CPU。

AI 助手（悬浮球）
开启后设置页右下角出现 AI 悬浮球，可询问扩展用法、主题/字号/检测开关等设置问题（基于 GLM 大模型，不分析当前网页）。
本地规则引擎（离线秒回）
内置关键词规则引擎，覆盖扩展设置 / 主题 / 字号 / 检测开关 / 急救箱等常见问答，零延迟、离线可用、零体积。可随时开关：关闭后仅在你开启「允许云端 GLM 增强」时走云端。
允许云端增强
本地规则未命中时，是否允许调用云端大模型作补充。默认关闭，避免频繁消耗云端额度；开启后仅在本地规则未命中时兜底（使用所选模型）。
Max 模式
开启后系统优先调用云端模型辅助（更聪明、更自由），并自动关闭下方的「本地规则引擎」与「允许云端增强」开关，仅保留云端 AI 模型辅助；当云端遇到无法处理的问题时再回退到本地规则。关闭本模式即恢复本地引擎默认开启。
后台自动 AI 分析网页
开启后，浏览网页时由扩展在后台自动将页面内容发送给云端 AI，按钓鱼 / 仿冒 / 诈骗 / 品牌核验等规则研判风险；AI 会先推断页面所属品牌的官方域名，后台再比对当前域名是否匹配官方，不匹配即判定仿冒并以页面提示呈现。无需手动触发，随页面加载自动生效（依赖 Max 模式）。
借助云端 AI 分析扫描文件
开启后，在「银狐扫描」中扫描出可疑 / 报毒文件时，扩展将本地提取的可疑特征摘要（文件名、大小、魔数、导入表、命中特征等，不含文件正文）发送给云端 AI 作辅助研判，并在结果卡片追加「云端 AI 辅助分析」一行。纯本地判定不受影响，失败静默（依赖 Max 模式）。
AI 语音播报
开启后，AI 回复会用微软 Edge 神经语音朗读出来（晓晓女声 / 云希男声，免费、自然、不上传内容）。默认关闭。
